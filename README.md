# Shlok Verma — Portfolio v2

> AI & Backend Developer · Bangalore, India  
> React + Vite · Three.js · Framer Motion · GSAP · Tailwind

---

## 🚀 Quick Start

```bash
npm install
npm run dev
# Opens at http://localhost:5173
```

## 📦 Deploy

```bash
npm run build     # → /dist
vercel            # instant deploy
```

```
src/
├── components/

│   └── ThreeScene.jsx      # Three.js 3D particles + floating geometry
├── sections/
│   ├── HeroSection.jsx     # Typewriter + GSAP entry + Three.js
│   ├── AboutSection.jsx    # Timeline + certifications
│   ├── SkillsSection.jsx   # 3D tilt cards + animated bars
│   ├── ProjectsSection.jsx # All 8 projects with Live + GitHub links
│   ├── SaaSSection.jsx     # DevSecureAuth features + pricing

│   └── ContactSection.jsx  # Form + WhatsApp CTA
├── hooks/

```
